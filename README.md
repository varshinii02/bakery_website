# Baker's Magic Website

A simple and attractive bakery website developed using HTML, CSS, and JavaScript.  
This project helps bakery businesses showcase their products online and attract customers through a clean and user friendly interface.

---

## Features

- Home page with bakery product display
- Cake and cupcake sections
- Simple login page
- Attractive UI design
- Easy website navigation
- Static responsive web pages

---

## Technologies Used

- HTML5
- CSS3
- JavaScript


---


## Project Objective

The main objective of this project is to help bakery businesses promote their products digitally and improve customer reach through an online platform.
